<h4 class="anchor" id="task-rules" data-title="Условия выполнения">Условия выполнения</h4>
<p>Ключевые действия следует выделять как транзакции, именуя их по установленному образцу (пример: UC2A_T02_login).</p>
<p>В заданиях по Web Tours необходимо исключить ситуацию, когда покупается билет на рейс с совпадающими значениями arrival/departure. Приветствуется широкое использование параметризации.</p>

<hr/><h4 class="anchor" id="task-1a" data-title="Задание 1A">Задание 1A: RegEx</h4>
<p>Создать сценарий JMeter, выполняющий следующие действия:</p>
<ol><li>открыть страницу на Хабре, посвященную регулярным выражениям (https://habr.com/ru/post/349860/);</li>
    <li>получить список всех основных разделов (веделены в содержании жирным шрифтом);</li>
    <li>вывести полученные данные в виде ответа JSR223-сэмплера.</li>
</ol>

<hr/><h4 class="anchor" id="task-1b" data-title="Задание 1B">Задание 1B (дополнительное)</h4>
<p>Создать сценарий JMeter, выполняющий следующие действия:</p>
<ol><li>открыть страницу на Хабре, посвященную регулярным выражениям (https://habr.com/ru/post/349860/);</li>
    <li>получить список всех основных разделов (веделены в содержании жирным шрифтом);</li>

</ol>

<hr/><h4 class="anchor" id="task-2a" data-title="Задание 2A">Задание 2A: Web Tours - добавление билета</h4>
<p>Для выполнения данного задания потребуется Web Tours Sample Application</p>
<p>Создать сценарий JMeter, выполняющий следующие действия:</p>
<ol><li>войти на сайт под пользователем <b>jojo</b> (pass = bean);</li>
    <li>купить билет на любой рейс;</li>
    <li>выйти из системы.</li>
</ol>

<hr/><h4 class="anchor" id="task-2b" data-title="Задание 2B">Задание 2B: Web Tours - удаление билетов</h4>
<p>Для выполнения данного задания потребуется Web Tours Sample Application</p>
<p>Создать сценарий JMeter, выполняющий следующие действия:</p>
<ol><li>войти на сайт под пользователем <b>jojo</b> (pass = bean);</li>
    <li>отменить все зарезервированные билеты (cancel all);</li>
    <li>выйти из системы.</li>
</ol>

<hr/><h4 class="anchor" id="task-2c" data-title="Задание 2C">Задание 2C (дополнительное)</h4>
<p>Для выполнения данного задания потребуется Web Tours Sample Application</p>
<p>Создать сценарий JMeter, выполняющий следующие действия:</p>
<ol><li>зарегистрироваться на сайте в качестве нового пользователя со случайным именем и паролем;</li>
    <li>купить билет(ы) (от имени зарегистрированного в пункте 1 пользователя) на случайный рейс - в 75% случаев - в один конец, иначе - туда и обратно (Roundtrip ticket);</li>
    <li>выйти из системы.</li>
</ol>
<p>Генерируемые имена и пароли пользователей должны сохраняться в файл в целях организации возможности дальнейшей проверки результатов выполнения скрипта в WEB-интерфейсе.</p>
